# Wi-Fi QR Card

Make a printable card that guests scan with their phone camera to join your Wi-Fi. No typing long passwords, no "is that a zero or an O?"

Made by [Davis Tech Support](https://davis-tech-support.com) in Farmville, Virginia.

## Features
- Works with WPA2, WPA3, WEP, open, and hidden networks
- Choose whether the password is printed on the card
- Print 1 large card, 4 cards, or 8 small cards per page (cut them out for tables or rooms)
- Save the code as a PNG or SVG for signs, menus, or slides
- Four card colors, with or without the Davis Tech Support logo
- Works offline after the first visit

## Privacy
The QR code is made entirely in the browser. The password is never sent anywhere, and it's only saved on the device if you tick "Remember the password."

## Deploy
Drag this folder onto Netlify, or connect the repository (no build command). It also works on GitHub Pages, or by opening `index.html` on your computer.
